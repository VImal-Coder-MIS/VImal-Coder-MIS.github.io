# AAP Attendance

Employee attendance app for **Atlantic Agro Plast**: check in and check out with a selfie, inside the office geofence.

by Vimal Verma

- **App:** https://vimal-coder-mis.github.io/
- **Server:** Google Apps Script + Google Sheets (the `API_URL` in `config.js`)
- **Android app:** `download/AAP-Attendance.apk`, built from this site with PWABuilder

No employee data, PINs or passwords are stored in this repository. Everything stays in the company Google Sheet.
